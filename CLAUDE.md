# About This Repo

This is Aashish's daily Python practice repo.
He is learning Python from scratch, practicing every day.

## Who Aashish Is
- Beginner Python learner (currently on Day 4)
- Works as a DevOps/Performance engineer professionally
- Uses Neovim (kickstart config) as his editor
- Learns best through real-world analogies — always use them
- Prefers short, clear explanations over technical jargon

## The Error Journal (`/errors/`)
The main purpose of this repo is to build a personal error reference book.

**Rules for every error entry:**
- Follow the template in `errors/README.md` exactly
- Always explain with a real-world analogy
- Always show: the error message → what it means → what broke → the fix → memory tip
- Keep it simple — write as if explaining to someone who just started coding

## Adding a New Error Entry
When Aashish hits an error and asks for an explanation:
1. Explain it conversationally first
2. Then ask if he wants to add it to the journal
3. Place it in the correct category file under `/errors/`
4. Follow the template

## Repo Structure
- `/errors/`        → error journal (categorized markdown files)
- `/practiceSets/`  → daily practice scripts (Day1, Day2, ...)
- Root `.py` files  → small experiments and mini projects

## How to Interact
- Don't assume prior Python knowledge
- Always use analogies
- When fixing code, explain WHY not just WHAT
